Teil A · allein · etwa 1 Stunde

Was du vorbereitest

Alles in Teil A kannst du ohne Valentin machen, in beliebiger Reihenfolge. Am Ende schickst du ihm die vier Angaben aus dem Kasten auf Seite 4. Nimm überall dieselbe E-Mail-Adresse — am besten info@hahntime.com —, dann passen die Konten später zusammen.

1

GitHub-Konto anlegen

Hannes5 Minuten

GitHub ist die Ablage für den Code der Website. github.com → Sign up → E-Mail, Passwort, Benutzername (z. B. hahnundvo). Bestätigungsmail anklicken. Danach unter Settings → Password and authentication die Zwei-Faktor-Anmeldung einschalten (Handy-App).

Fertig, wenn: du dich auf github.com einloggen kannst.
An Valentin schicken: deinen GitHub-Benutzernamen.
2

Claude-Konto mit Abo

Hannes5 Minuten

claude.ai → Konto anlegen (gleiche E-Mail) → Abo wählen. Pro reicht zum Start; wenn du merkst, dass die Nutzungsgrenze erreicht wird, auf Max wechseln. Dieses Konto benutzt später auch Claude Code auf deinem Mac.

Fertig, wenn: das Abo aktiv ist (oben links steht „Pro" oder „Max").
3

Shopify mit Claude verbinden

Hannes3 Minuten

Damit Claude in deinem Shop Uhren anlegen darf. In claude.ai unten links auf deinen Namen → Einstellungen → Connectors (auch „Integrationen") → Shopify → Verbinden. Es öffnet sich die Shopify-Anmeldung: mit deinem Shop-Login (info@hahntime.com) anmelden, den Shop tami1g-0j wählen, den Zugriff bestätigen.

Fertig, wenn: Shopify in der Connector-Liste als „verbunden" steht.
An Valentin schicken: ein Wort — „Shopify verbunden".
4

Vercel-Konto, Team und Pro-Tarif

Hannes10 Minuten

Vercel liefert die Website aus. vercel.com → Sign Up → „Continue with GitHub" (wichtig: mit dem GitHub-Konto aus Schritt 1 — so kann Vercel später deinen Code sehen). Dann ein Team anlegen: Name Hahn & Vo. Im Team: Settings → Billing → Upgrade to Pro, Karte hinterlegen. Der Pro-Tarif enthält deinen Sitz als Owner; Valentin kommt später als kostenloser „Viewer" dazu.

Warum Pro und nicht kostenlos: Vercel erlaubt den Gratis-Tarif nur für private, nicht-kommerzielle Seiten, und man kann niemanden ins Team holen. Ein laufender Uhrenshop gehört auf Pro — sonst kann Vercel das Konto pausieren.
Fertig, wenn: unter Settings → Billing „Pro" steht und ein Zahlungsmittel hinterlegt ist. Noch kein Projekt anlegen — das kommt per Übertragung in Teil B.
An Valentin schicken: den Team-Namen so, wie er in der Adresszeile steht (vercel.com/…).
5

Resend-Login prüfen

Hannes2 Minuten

Resend verschickt die Mails aus „Suchauftrag" und „Ankauf" an info@hahntime.com. Das Konto gehört dir schon — einmal einloggen: resend.com → Sign in. Unter API Keys liegt der Schlüssel „hahn-vo-website", den Valentin im Website-Hosting hinterlegt hat. Nichts löschen — den Schlüssel erneuern wir zusammen in Teil B, damit kein Schlüssel mehr in Umlauf ist, den Valentin kennt.

Fertig, wenn: du eingeloggt bist und den Schlüssel unter API Keys siehst.
An Valentin schicken: „Resend-Login klappt".
6

Claude Code als Mac-App installieren

Hannes5 Minuten

Du brauchst kein Terminal. Claude Code gibt es als Mac-App: claude.com/claude-code → Download für Mac → installieren → mit deinem Claude-Konto anmelden. Alles Weitere, was der Mac im Hintergrund braucht (git, Python, den Browser fürs Inseratlesen), installiert Claude selbst, sobald wir in Teil B das Projekt öffnen — du bestätigst nur Apple-Dialoge und gibst einmal dein Mac-Passwort ein.

Wer lieber im Terminal arbeitet: npm install -g @anthropic-ai/claude-code — dann ist der Start claude im Projektordner. Ergebnis ist dasselbe.

Fertig, wenn: die App startet und dein Name oben steht. Außerdem: macOS ist aktuell, du kennst dein Mac-Passwort, und du kannst den Bildschirm teilen (FaceTime, Zoom, Teams — egal was).

Was wir in Teil B nicht mehr tun müssen

Das steckt schon im Projekt und wandert mit dem Repo mit: die fünf Skills (Uhr anlegen, Status setzen, löschen, Bilder ändern, Website ändern), die Werkzeuge dahinter, die Regeln (z. B. Besteuerung, Bildreihenfolge, interne Codes), und eine Liste aller Fehler aus dem Aufbau mit ihrer Lösung. Nichts davon hängt an Valentins Konto.

Kurz gesagt: Teil A sind Konten. Teil B ist Verbinden und Üben. Danach machst du im Alltag nur noch eins: Claude sagen, was passieren soll.

3

Probelauf — Hannes legt eine Uhr an

Hannes tipptValentin schaut zu60–90 Minuten

Ein Satz im Claude-Fenster, mit dem echten Inserat aus deiner Vorbereitung:

https://www.kleinanzeigen.de/s-anzeige/…   hochladen, Preis wie im Inserat

Mehr nicht. Claude liest das Inserat (ein Browserfenster geht kurz auf — gewollt), holt die Bilder, wählt Cover und zweites Bild nach der Regel „Set-Foto, sonst Frontbild", entscheidet Besteuerung und Felder, legt die Uhr in Shopify an, prüft die Website und schreibt dir drei bis fünf Sätze: Link, Preis, Besteuerung mit Grund, was Cover und zweites Bild zeigen, und was unsicher war. Zwischendurch fragt Claude nichts — nur wenn der Preis oder die Artikelnummer fehlen, oder bevor es etwas löscht.

Danach öffnest du den Link und siehst dir die Uhr an. Gefällt dir das zweite Bild nicht, ein Satz genügt: Bei p… das Set-Foto als zweites Bild. Und zwei weitere Sätze, damit du beides einmal gemacht hast:

p… auf reserviert
Reservierung bei p… wieder raus
Fertig, wenn: die Uhr live ist, der Bericht kam, Reservieren und ein Bildwechsel geklappt haben — und Hannes die Sätze selbst getippt hat.
Wenn etwas hakt: Claude meldet „FEHLER: …" mit Ursache und macht dort weiter, wo es stand. Kleinanzeigen-Sperre: warten oder Fotos in einen Ordner ziehen und „Fotos liegen in ~/Desktop/neue-uhr" sagen. Beim allerersten Mal fragt Claude Code für jedes Werkzeug (Skripte, Shopify, Git) einmal nach einer Erlaubnis — „Immer erlauben" wählen, danach nie wieder.
